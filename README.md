# Ghar Stays

Ghar Stays offers welcoming, furnished apartment stays in Lahore. Find a place in Gulberg, DHA or Johar Town, then send a booking enquiry to connect with a local host.

## Pages

- [index.html](./index.html) — Browse apartments and send a booking enquiry.
- [about.html](./about.html) — Learn about Ghar Stays and find answers to common questions.

## Features

- Filter apartment listings by area.
- Booking form with a check for an 11-digit phone number starting with `03`.
- Price calculator that totals the nightly rate across the selected dates.
- WhatsApp button for contacting the Ghar Stays team.
